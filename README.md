# 基于 C# 的工业扫码枪串口通信模块

## 项目简介
本项目是一个基于 C# WinForms 开发的上位机扫码追溯模块。主要用于生产流水线上的条码扫描与数据采集。通过 RS232/虚拟串口与扫码枪进行通信，实时接收、解析并展示扫码数据，支持重复扫码校验与日志记录。

## 技术栈
* **开发语言**：C# (.NET 6 / WinForms)
* **通信协议**：SerialPort (串口通信)
* **关键技术**：多线程跨域 UI 更新 (Invoke / Action 委托)、INI 文件持久化、事件订阅机制

## 核心功能
1. **串口配置与连接**：动态加载本机可用 COM 口，支持波特率、数据位等参数设置，并将参数保存至本地配置文件。
2. **数据接收与处理**：基于 `DataReceived` 事件监听数据，解决串口数据分包、粘包问题，自动去除换行符（Trim）并过滤空数据。
3. **线程安全更新 UI**：通过 `InvokeRequired` 判断与 `Action` 委托，确保在后台接收线程中安全、无异常地更新界面列表控件（ListBox）。
